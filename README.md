# Premium Addition & Subtraction Calculator

A modern, glassmorphic calculator built with HTML, CSS, and vanilla JavaScript.

## Features
- **Addition & Subtraction**: Only supports basic mathematical operations as requested.
- **Premium UI**: Dark mode with glassmorphism, gradients, and soft neon glows.
- **Keyboard Support**: Full keyboard integration (0-9, +, -, Enter, Backspace, Esc).
- **Responsive Design**: Works beautifully on all screen sizes.
- **Micro-animations**: Smooth hover and click effects for a premium feel.

## How to Run
Simply open `index.html` in any web browser.

## Tech Stack
- **HTML5**: Semantic structure.
- **Vanilla CSS**: Modern CSS variables, glassmorphism, and animations.
- **JavaScript**: Core logic for calculations and keyboard events.
